# План автотестов Questify

## Текущее покрытие
- `tests/e2e/auth.spec.ts` — регистрация, логин, логаут
- `tests/unit/gamification-levels.test.ts` — расчёт уровней

---

## Блок 1 — Юнит-тесты (Vitest)

### 1.1 Геймификация
- **XP-расчёт**: все приоритеты (P1=50, P2=30, P3=15, P4=5)
- **Уровни**: граничные значения (0 XP → lvl 1, 100 → lvl 2, ...)
- **Множитель streak**: x1.0 / x1.5 / x2.0
- **Ачивки**: проверка условий (first_task, getting_started, hard_worker, week_warrior, monthly_master, perfect_day, planner)
- **XP_REWARDS**: planStep, planCompleted константы

### 1.2 Серверные экшены
- **tasks.ts**: createTask (валидация), updateTask (смена статуса/приоритета), deleteTask, getTasks
- **plans.ts**: createPlan, togglePlanItem, getPlanById (расчёт прогресса)
- **ideas.ts**: createIdea, deleteIdea, getIdeas
- **auth.ts**: signIn, signUp, signOut

### 1.3 Утилиты
- **groupTasksByStatus**: разбивка по 3 статусам, пустой массив
- **groupTasksByPriority**: разбивка по 4 приоритетам
- **Zod-схемы**: валидация входных данных (CreateTaskInputSchema, UpdateTaskInputSchema, etc.)
- **avatarColor**: детерминированность, диапазон

## Блок 2 — E2E тесты (Playwright)

### 2.1 Аутентификация
- Регистрация → редирект на дашборд
- Логин с валидными креденшелами → дашборд
- Логин с невалидными → ошибка
- Логаут → редирект на /login
- Доступ к /dashboard без логина → редирект на /login

### 2.2 Задачи (Tasks)
- Создание через форму (title + description + priority)
- Быстрое создание (инлайн-поле + Enter)
- Быстрое создание (инлайн-поле + кнопка)
- Фильтрация по поиску
- Фильтрация по приоритету
- Фильтрация по статусу
- Сброс фильтров
- Удаление задачи

### 2.3 Kanban
- Отображение задач по колонкам (Todo / In Progress / Done)
- Drag-and-drop: задача меняет статус
- Drag-and-drop: задача не дублируется при быстрых перетаскиваниях

### 2.4 Matrix (Eisenhower)
- Отображение задач по квадрантам (P1-P4)
- Drag-and-drop: задача меняет приоритет
- Кнопка Auto-distribute → показывает инфо

### 2.5 Планы (Plans)
- Создание плана
- Добавление элемента плана
- Отметка элемента как выполненного
- Прогресс-бар обновляется

### 2.6 Идеи (Ideas)
- Быстрое создание (инлайн-поле)
- Удаление идеи
- Отображение источника (Web / Telegram)

### 2.7 Профиль
- Отображение имени, статистики, ачивок
- Копирование ID (с префиксом /link)
- Переключение темы (системная → светлая → тёмная)

### 2.8 Дашборд
- Отображение статистики (tasks, plans, XP, streak)
- Сердце: анимация, цвет зависит от окружения
- Редирект при отсутствии авторизации

### 2.9 Telegram вебхук
- GET /api/telegram → 200 OK
- POST /api/telegram /start → ответ с инструкцией
- POST /api/telegram /link <id> → upsert в telegram_chats
- POST /api/telegram текстовая идея → создание через service_role

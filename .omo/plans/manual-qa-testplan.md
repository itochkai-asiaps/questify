## 1. D7 — Draggable Backlog/Todo разделитель

### D7.1 — Перетаскивание разделителя
| # | Сценарий | Шаги | Ожидаемый результат |
|---|---|---|---|
| 1.1 | Разделитель виден | Открыть страницу Tasks с несколькими задачами | Видна линия «Backlog» между активными задачами и backlog |
| 1.2 | Курсор меняется | Навести курсор на разделитель | Курсор становится `grab` |
| 1.3 | Перетаскивание вниз | Захватить разделитель, потянуть вниз до задачи | Задачи выше разделителя → Todo, ниже → Backlog |
| 1.4 | Перетаскивание вверх | Захватить разделитель, потянуть вверх | Backlog-задачи выше разделителя → становятся Todo |
| 1.5 | DragOverlay | Тянуть разделитель | Виден полупрозрачный разделитель с primary-цветом |
| 1.6 | Оптимистичный UI | Отпустить разделитель | Задачи мгновенно перемещаются между секциями |
| 1.7 | Обновление после перезагрузки | Перезагрузить страницу после перетаскивания | Статусы задач сохранены |

### D7.2 — Предыдущий статус (D7a)
| # | Сценарий | Шаги | Ожидаемый результат |
|---|---|---|---|
| 2.1 | Сохранение статуса в backlog | Перетащить задачу InProgress в backlog (разделителем или drag) | Статус задачи должен сохраниться |
| 2.2 | Восстановление статуса | Вернуть задачу из backlog в активные (разделителем вверх) | Восстановлен предыдущий статус (todo/in_progress/done) |
| 2.3 | Новая задача в backlog | Создать задачу через quick-create в backlog | Дефолтный статус = backlog, previous_status = NULL |
| 2.4 | Возврат без previous_status | Вернуть задачу из backlog (без предыдущего статуса) | Статус становится todo |

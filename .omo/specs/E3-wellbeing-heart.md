# E3 — Дневник самочувствия (Wellbeing Heart)

> Версия: 1.0 | Создано: 2026-07-09 | Источник: `.omo/plans/roadmap.md` (строки 41-46)

## Описание

HP-бар в форме сердца на дашборде. Пользователь двигает курсором по сердцу — видит preview уровня настроения (0-100). Клик сохраняет запись. Без диалогов, без слайдеров — только курсорный трекинг.

## Функциональные требования

### FR-1: Интерактивное сердце
- **FR-1.1** Курсорный трекинг: движение мыши по SVG-сердцу меняет уровень заполнения в реальном времени
- **FR-1.2** 20 зон по 5% (0, 5, 10, …, 95, 100)
- **FR-1.3** Заполнение снизу вверх: 0% = пустое, 100% = полное
- **FR-1.4** Hover: tooltip с процентом справа от сердца
- **FR-1.5** Клик: мгновенное сохранение выбранного уровня
- **FR-1.6** НЕТ диалогов подтверждения — клик = сохранить

### FR-2: Визуальное оформление
- **FR-2.1** Градиент: жёлтый (100%, верх) → красный (0%, низ)
- **FR-2.2** Стейджинг: `#fde047` → `#eab308` (жёлто-янтарный)
- **FR-2.3** Прод: `#ef4444` → `#dc2626` (красный)
- **FR-2.4** Пустое сердце: полупрозрачный фон того же цвета
- **FR-2.5** Обводка: тёмная (#7f1d1d стейджинг / #991b1b прод)
- **FR-2.6** **Пульсация**: сердце пульсирует (анимация heartbeat)

### FR-3: Сохранение и валидация
- **FR-3.1** Шкала: 0-100 (целые числа)
- **FR-3.2** Лимит: ≤48 записей в день (24-часовое скользящее окно)
- **FR-3.3** После сохранения: показывать поле ввода заметки на 5 секунд
- **FR-3.4** Заметка: макс 500 символов, таймер не тикает пока поле в фокусе
- **FR-3.5** Заметка — **PATCH существующей записи**, не создавать новую
- **FR-3.6** После сохранения заметки: показывать «✓ Saved» на 1.5 сек

### FR-4: Отображение состояния
- **FR-4.1** При загрузке: спиннер
- **FR-4.2** Есть запись за сегодня: эмодзи + лейбл (😞 Awful / 😐 Meh / 🙂 Okay / 😊 Good / 😄 Great)
- **FR-4.3** Нет записи: «Click to set mood»
- **FR-4.4** Ошибка: показать текст ошибки вместо «Click to set mood»
- **FR-4.5** Во время сохранения: спиннер внутри сердца

### FR-5: Мобильная версия
- **FR-5.1** На мобильном: клик по позиции определяет уровень (hover недоступен)
- **FR-5.2** Размер сердца: `size-36` (мобильный) / `size-44` (десктоп)

## График настроения (MoodChart)

### FR-6: 7-дневный график
- **FR-6.1** Ось X: дни недели (Sun, Mon, Tue, Wed, Thu, Fri, Sat)
- **FR-6.2** Ось Y: 0-100 с делениями 0, 50, 100
- **FR-6.3** Сетка: горизонтальные линии на 0, 25, 50, 75, 100
- **FR-6.4** Точки: эмодзи по шкале (😞 0-20 / 😐 21-40 / 🙂 41-60 / 😊 61-80 / 😄 81-100)
- **FR-6.5** Если несколько записей в день — среднее арифметическое
- **FR-6.6** Среднее за неделю: `Avg: N/100`
- **FR-6.7** Тренд: сравнивать первую и вторую половину недели (±5 порог)
- **FR-6.8** Пустое состояние: график скрыт (return null)

### FR-7: Загрузка данных
- **FR-7.1** При загрузке: скелетон-карточка
- **FR-7.2** Ошибка загрузки: график скрыт, ошибка в консоли

## Нефункциональные требования

- **NFR-1**: Все server actions возвращают `{ data?, error? }`, не бросают исключений
- **NFR-2**: Zod safeParse на всех границах (не parse)
- **NFR-3**: revalidatePath("/dashboard", "layout") после сохранения
- **NFR-4**: 24-часовое скользящее окно для фильтрации «сегодня» (timezone-agnostic)

## Структура БД

```sql
CREATE TABLE wellbeing_entries (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  mood_score INTEGER NOT NULL CHECK (mood_score >= 0 AND mood_score <= 100),
  note TEXT,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
```

## Acceptance Criteria

| # | Сценарий | Ожидаемый результат |
|---|---|---|
| AC-1 | Навести курсор на сердце, двигать вверх-вниз | Заполнение меняется, tooltip показывает % |
| AC-2 | Кликнуть на 75% | Сохранено, эмодзи 😊 Good, поле заметки показано |
| AC-3 | Ввести заметку, нажать Enter | «✓ Saved», запись обновлена (не дублирована) |
| AC-4 | Обновить страницу | Последний уровень за сегодня показан |
| AC-5 | Сделать 3 записи за день с разными уровнями | График показывает среднее за этот день |
| AC-6 | Нет записей | График скрыт, сердце показывает «Click to set mood» |
| AC-7 | 49-я запись за день | Ошибка «Limit reached: 48 entries per day» |
| AC-8 | Не авторизован | Ошибка «Not authenticated» |

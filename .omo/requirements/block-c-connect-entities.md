# Блок C — Связать сущности

## Новые серверные экшены
Файл: `src/lib/actions/conversions.ts`

### `convertIdeaToTask(ideaId: string)`
1. Получить идею по id
2. Создать задачу: title (обрезать до 200), description (обрезать до 2000), priority=p3
3. Удалить идею
4. Вернуть результат

### `convertIdeaToPlan(ideaId: string)`
1. Получить идею по id
2. Создать план: title (обрезать до 200), description (обрезать до 2000)
3. Удалить идею
4. Вернуть результат

### `convertPlanItemToTask(itemId: string)`
1. Получить элемент плана по id
2. Создать задачу: title (обрезать до 200), priority=p3
3. Удалить элемент плана
4. Вернуть результат

## UI

### Идеи (`ideas/page.tsx`)
- На каждой карточке: две кнопки «→ Task» и «→ Plan» (между бейджем и удалением)
- После конвертации: toast «Converted to Task» / «Converted to Plan», идея исчезает

### План (`plans/[id]/page.tsx`)
- На каждом НЕзавершённом элементе: кнопка «→ Task» (после кнопки удаления)
- После конвертации: toast «Converted to Task», элемент исчезает

## Правила
- После конвертации исходная сущность удаляется ✅
- Toast-уведомление показывается ✅
- На плане — только на незавершённых элементах ✅

- Сложность: ★★☆
